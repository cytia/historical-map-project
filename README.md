# 中国历史交互地图

一个面向公众与历史爱好者的开源历史 GIS 网页应用。项目将以统一的时间模型持续收录中国不同历史时期的政区、地点、自然地理和历史事件。

第一版以公元 1600 年左右为基准，计划展示晚明两京十三布政使司、府州县治所、主要城市、河流湖泊、大运河和九边军镇。

## 技术方案

- React + TypeScript + Vite
- MapLibre GL JS
- Zustand
- JSON / GeoJSON
- Rust 数据校验与转换工具
- 后续按规模引入 PMTiles/MVT、Axum 和 PostgreSQL/PostGIS

第一版采用静态数据和静态部署，避免在没有需求时引入服务器复杂度。

## 数据原则

- 朝代用于浏览，年份决定地图状态。
- 地点、历史名称、行政单位和边界分别建模。
- 不确定边界必须明确标识，不能表现为精确事实。
- 每条历史数据记录来源、有效时间、定位精度和可信度。
- 第三方资料遵守各自许可；公益开源不等于可以自由再分发。

详细要求见 [历史数据规范](docs/historical-data.md)。工程约定见 [工程规范](docs/engineering.md)。当前计划见 [路线图](docs/roadmap.md)。

## 现代地理参考层

可选的自然地理参考层使用裁剪后的 Natural Earth 10m 物理图层，当前只保留陆地、自然湖泊和主要河流中心线，不包含现代道路、建筑、城市面或现代城市标签。该图层仅用于空间定位和地图阅读，不作为公元 1600 年海岸线、河道、地貌或行政边界的历史依据；山川地貌晕渲仍由独立的 NOAA ETOPO PMTiles 提供。Natural Earth 来源、版本和构建方式见 `tools/reference/README.md`。
