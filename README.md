# 历史地图计划

历史地图计划（Historical Map Project）是一个面向公众与历史爱好者的开源历史地图项目。

项目希望用可浏览、可查询的地图，呈现中国不同历史时期的政区、地点、自然地理和历史事件。

[在线体验](https://chronotabula.inkore.ink/) · [数据授权说明](docs/data-license.md)

## 第一版：晚明历史地图

第一版以公元 1600 年左右（万历二十八年前后）为基准，逐步展示：

- 两京十三布政使司及其府、州、县；
- 都司、行都司、留守司、卫所等军事体系；
- 宣慰、土司、羁縻等特殊治理单位；
- 历史地点、名称和隶属关系；
- 人口、土地、税负等历史信息；
- 主要山川、河流和湖泊。

这些内容将随着资料整理和研究进展持续更新。

## 明代时间节点

明代部分计划以四个具有代表性的时间节点呈现历史变化：

- 洪武二十六年（1393）；
- 弘治十五年（1502）；
- 万历二十八年（1600）；
- 崇祯十七年（1644）。

## 长期计划

项目将以明代首版为起点，逐步向更早时期延伸，后续优先制作两宋、五代和唐代，最终覆盖中国历史上更多时期。

## 阅读说明

历史资料与现代地图并不总能一一对应。部分地点目前只能定位到现代城市、县治或大致区域，不能直接理解为已经确认的古代城址。项目会尽量在页面和数据说明中标注相关不确定性。

本项目面向历史研究、教育和公众浏览，地图内容不作为导航、测绘、工程或其他高风险用途的依据。

历史地图计划是一个需要长期投入的庞大工程。从历史点位坐标的校验、资料核对，到功能开发与版本维护，每一步都需要持续投入。

如果这个项目对你有所帮助，欢迎在 GitHub 点亮一颗 Star。这是对独立开发者最直接、最有力的鼓励，也能帮助更多人发现这款工具。

## 项目状态

当前进度：

- 已完成明代两京十三布政司辖下府、州、县共 1,563 个历史点位的坐标审核与录入；
- 依据万历六年记录，已完成全国及各省人口、田土、赋税数据的整理与录入。

下一步：

- 制作人口、田土、赋税着色地图；
- 开展全国都司、行都司、留守司及其下辖卫所的坐标审核与录入。
