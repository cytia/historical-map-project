## 申请目标

申请应明确针对未来用途，不把当前免费研究状态描述为已经发生的商业使用。建议把权限拆开询问，避免因范围过宽而被整体拒绝：

1. 免费公共地图展示；
2. 爱发电持续开发赞助；
3. 摩点回报型众筹及宣传截图；
4. 个人和机构订阅；
5. 付费产品中的地图显示与搜索；
6. 静态图片、报告和高清地图导出；
7. API 是否可以返回 CHGIS 派生结果；
8. 是否允许用户下载原始坐标；
9. 是否允许服务器缓存已经查询的记录；
10. 当前个人申请取得的许可是否可由未来项目公司承接。

首轮优先申请较窄的“商业展示与搜索许可”：允许在免费和付费在线地图中显示、搜索 CHGIS Temporal Gazetteer 点位，但不提供 CHGIS 原始记录的批量下载、转售或独立数据包。

## 项目情况说明

随申请提供一页项目简介，至少包含：

- 项目第一版以公元 1600 年前后为时间切片；
- 当前覆盖两京十三布政使司及府、州、县治所；
- 行政名录和隶属关系主要依据《明史·地理志》等史料校勘；
- CHGIS 主要用于历史治所定位、有效时间筛选和同名消歧；
- 项目当前收录 1,641 个历史地点；云贵 14 点、福建 47 点和江西 64 点替换后，仍有 1,022 个地点记录明确采用 CHGIS Temporal Gazetteer 点位，约占全部地点的 62.3%（替换前基线为 1,147 个、69.9%）；
- 当前未替换记录涉及 1,012 个唯一 CHGIS 记录编号和 1,000 组唯一坐标；替换前基线为 1,139 个编号和 1,125 组坐标。附郭、共治或项目实体拆分会造成编号或坐标复用，三种数量不能互换；
- 详细使用范围见 [CHGIS 点位使用清单与独立替换方案](chgis-point-inventory.md)；
- 当前不申请 CHGIS V6 多边形的商业使用权；
- 项目不会把 CHGIS 数据标为原创；
- 项目愿意持续署名、链接来源并反馈校勘发现；
- 当前项目处于免费、非商业的研究与开发阶段；
- 未来收入计划包括爱发电、摩点和个人或机构订阅。

可以说明项目由历史爱好者、小说创作者和独立开发者发起，现阶段没有机构团队或稳定项目经费。自动化和 AI 工具只辅助资料整理、数据校验和软件开发，历史来源核查、同名消歧、迁治判断与最终审核仍由人工完成。

## 未取得授权时的后续措施

### 商业授权被拒，但允许继续非商业使用

- 免费研究版本继续完整署名并遵守 CC BY-NC 4.0；
- 不把 CHGIS 地图访问、坐标、导出或 API 作为爱发电权益；
- 摩点宣传材料和回报只使用商业安全数据；
- 订阅产品不加载 CHGIS 或其他 NC 数据；
- 按路线图继续独立重建和替换现有点位。

可以再询问一次更窄的方案，例如仅限在线显示、不允许下载、限定地区、限定一年、收入达到门槛后付费或按收入分成。再次被拒后不继续施压。

### 仅允许免费展示或开发赞助

- 要求对方把允许的资金渠道、展示范围、宣传截图和署名方式写入许可；
- 爱发电严格限定为开发过程支持，不提供 CHGIS 专属内容；
- 摩点和订阅继续使用独立重建数据；
- 授权期内同步完成替换，避免项目永久依赖过渡许可。

### 只允许在线展示，不允许导出

- 禁止坐标下载、批量导出和 CHGIS 数据 API；
- 检查浏览器网络响应是否直接暴露完整 CHGIS 数据包；
- 静态图片、打印和报告是否属于允许范围必须另行写明；
- 商业安全数据与 CHGIS 数据在存储和构建中分离。

### 授权费用或条件无法接受

- 不签署超出项目承受能力或阻止独立替换的排他条款；
- 询问独立开发者费率、试点许可、延期收费、收入门槛或分成方案；
- 比较授权总成本与独立重建成本；
- 谈判失败时按未取得商业授权处理。

### 没有回复

- 完成两次邮件和一次官方电话跟进后停止等待；
- 不把沉默解释为同意；
- 免费研究版继续按现有公共许可使用；
- 爱发电、摩点和订阅按最保守的数据隔离方案推进。

### 对方质疑当前使用

- 暂停争议数据的新发布和相关收费计划；
- 保存当前页面、署名、许可、数据清单、Git 历史和往来邮件；
- 不删除来源、不改写历史记录，也不在邮件中仓促承认侵权；
- 请对方具体指出争议记录、许可条款和期望的整改措施；
- 在继续公开或商业发布前寻求熟悉知识产权与数据库许可的律师意见。

## 商业发布底线

- CHGIS 授权成功是项目加速路径，不是项目继续存在的前提。
- 免费研究版本、商业安全版本和内部审计记录必须分离。
- 商业发布包只能包含明确允许商业使用的数据。
- 替换 CHGIS 点位必须重新取得候选坐标并完成独立历史判断，不能只修改来源标签、移动坐标或降低精度。
- 爱发电、摩点或订阅收入不能作为规避第三方许可条件的理由。
