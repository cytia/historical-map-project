# 乌思藏都司 1600 点位核验

核验日期：2026-08-05

本次核验只覆盖军事羁縻点位：都司、行都司、留守司、卫、军民元帅府、万户府为一级，所为二级。教王、法王及其封地不录入本项目数据。

## 核验结果

当前乌思藏都司及其关联军事羁縻名录应显示：

- 一级：乌思藏都司、俺不罗行都司、牛儿宗寨行都司、领司奔寨行都司、上邛部卫、俄力思军民元帅府、必力工瓦万户府、帕木竹巴万户府、仰思多万户府、沙鲁万户府、着由万户府；
- 二级：答笼千户所、葛剌汤千户所；
- 留守司：本轮文献未发现 1600 年乌思藏都司下的留守司记录。

现有数据已录入上述点位，并将元帅府、万户府作为独立一级点位处理。现有证据不足以把这些元帅府、万户府直接挂接到乌思藏都司，也不足以把答笼、葛剌汤千户所改挂到其中任何一个万户府，因此不生成臆测的隶属线。

## 排除项

教王、法王及其封地不录入单位、地点、名称或关系数据。俄力思军民元帅府与巴者万户府在早期史料中存在关联，但未确认其在 1600 年仍作为本项目点位及下级关系，故不新增巴者万户府。

## 来源核对

- 《明史》卷三百三十一“朵甘乌斯藏行都指挥使司”记载：永乐年间后置乌思藏牛儿宗寨行都指挥使司，又置上邛部卫；同一叙事还记载俺不罗行都司等乌思藏机构。
- 《大明太宗孝文皇帝实录》卷一百六十四、永乐十三年五月丙辰明确记载“设上邛部卫，命头目掌巴伯为指挥使”。
- “必里卫”未并入本体系：相关研究及史料将必里千户所／必里卫置于河州卫系统，不能因其出现在同一段西番沿革叙述中而挂接乌思藏都司。

## 点位限制

上邛部卫只取得“邛部—丁青”这一低置信度地名线索，地图使用现代丁青县代理坐标，精度标为 `area_only`、可信度标为 `low`。该点表达机构存在和大致区域，不表达明代卫城的精确位置。
