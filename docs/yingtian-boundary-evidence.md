# 应天府府级边界试验证据台账

本文是应天府公元 1600 年府级行政边界试验的研究记录，不是正式发布数据。当前只记录界址证据和相邻单位，不生成边界线或 GeoJSON。

## 研究状态

- 目标时间：公元 1600 年，允许使用覆盖该年的明代有效记录。
- 目标几何：应天府府级外轮廓；不制作八县发布面。
- 证据用途：八县四至、相邻关系和自然地理界址用于约束府级外轮廓。
- 当前阶段：文字证据整理；已核查部分线上页面的书目与文本载荷，但尚未完成原始影像核验、现代坐标匹配、边界段绘制和发布资格审查。
- 结论等级：以下为候选边界段，不等同于已确认边界。

界线类型互证页面：[《景定建康志》溧阳山川条目](https://www.shidianguji.com/mid-page/7428710673938645001)、[《至大金陵新志》溧阳州图考](https://www.shidianguji.com/book/SK0991/chapter/1la249ogcagwa)。前者明确石屋山相对溧阳县治的方位，后者记“葑埭牌”和“石屋山分流”，两者都只作历史互证。

空间对应的二级校验见[复旦 Temporal Gazetteer 的相关界线说明](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_32303)：该页依据宋代方志将石屋山／青山解释为今溧阳南部山地，并将葑埭牌解释为溧阳东界方向。该页所述对象是早期州界重建，不是 1600 年应天府府界；其 CHGIS 数据采用 CC BY-NC 4.0，故本项目只吸收文字判断，不读取或复制其点、线、面。

本轮锚点互证页面：[仪真县境条目](https://www.shidianguji.com/mid-page/7427223634294620170)、[宜兴县境《江南经略》条目](https://www.shidianguji.com/book/SK1396/chapter/1laqkhdjrx24v)。后出府志和地方文献只用于辨识异名、延续地名和寻找候选位置，不作为 1600 年边界的单一依据。

另有[万历《扬州府志》仪真县境条目](https://www.shidianguji.com/book/7543927473264656411/chapter/1lj1rfd1cyexm)记仪真县治西抵六合县褚家堡四十里，可与应天府志的县境条目互相校核。

## 内部约束与共享水域

以下记录不直接形成应天府外边界，但会约束八县组合后的外轮廓：

- 上元东至周郎桥与句容界，南至白米湖与江宁界，北至大江中流与六合界。
- 江宁东北界上元，西侧以大江中流与江浦相接，东南经乌刹桥与溧水相接。
- 句容西至上元周郎桥，南至溧水丁塘一带，北至仪真大江中流。
- 溧水东至溧阳，西至乌刹桥与上元相接，北至上义山与江宁相接。
- 石臼湖、丹阳湖和固城湖的水域范围与当时堤坝、水道变化需要单独核对，不能直接使用现代湖岸闭合边界。
- 《三吴水考》将丹阳湖记为与溧水、高淳、太平、宁国共界；这先作为共享水域线索，不直接判断宁国府是否存在连续陆界。

## 下一轮核查

1. 回看《万历应天府志》影像，校正 OCR 地名和卷页。
2. 为每个界址锚点建立现代候选坐标，并标记 `exact`、`approximate` 或 `disputed`。
3. 用《明史》卷四十及相邻府县志核对父链和相邻关系。
4. 确认河流、湖泊和山脊参考数据的许可、版本和时间适用性。
5. 只有在候选锚点和相邻关系稳定后，才开始绘制边界段。
