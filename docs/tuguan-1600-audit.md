# 1600 年土官机构核对

本表的“土官机构”采用数据模型中的 `jimiKind: native-office`，不把羁縻军事机构混入土官机构清单。行政辖区是独立的上下文关系，不是土官机构的上级点位。

## 核对口径

- 时间切片为万历二十八年（1600）；机构未能确认在该年有效时，不以其他时期记录替代。
- 土官系统的连接关系使用 `jimi-subordination`，只连接两个 `jimiUnits`，并要求二者属于同一 `jimiKind`。
- 所在府、州、县或省级辖区使用 `jimi-administrative-context` 记录，只用于资料展示和省级配色；若上下文指向府、州或县，渲染时沿行政 `parentId` 上溯至省级辖区，不绘制连线。
- 土官机构的点位必须有独立 `Place`、坐标、定位精度、来源和校勘记录；不能因为同名现代地名而自动补点。
- 完整逐点表由以下命令从当前数据生成：

```text
cargo run -p data-validator -- tuguan-audit
```

## 来源基线

本轮核对优先使用《明史》地理志、土司传及万历《大明会典·土官衙门》；不同史料的机构总数、名称和所属关系不一致时，保留来源差异，不把后世沿革强行投射到 1600 年。湖广的永顺、保靖及施州系统尤其需要区分宣慰、宣抚、安抚、长官和蛮夷长官不同层级；贵州的播州、贵州、金筑及各府属长官司需要区分土官系统与流官行政上下文；云南外徼宣慰、宣抚、安抚及御夷机构则需要单独核对有效年份。

可核对的公开原文包括《明史》卷四十四湖广、卷四十五广西和卷四十六云南贵州，以及《明史》湖广土司、贵州土司条。项目来源目录中的 `ming-shi-geography-four` 至 `ming-shi-geography-seven`、`ming-shi-guizhou-tusi`、`ming-shi-shizhou-tusi` 和 `wanli-ming-huidian-native-offices` 保存具体引用。

## 本轮修正

- 240 个现有土官机构均已有 `seatPlaceId` 和可用坐标；本轮没有在缺少独立史料和定位依据的情况下虚构新增点位。
- 为贵州 6 个根级机构、四川 5 个根级机构补充省级行政上下文；这些上下文只用于行政归属和配色，不作为地图连接线终点。
- 土官下属点位沿土官父级继承行政辖区，因此即使没有重复的行政上下文关系，也能获得正确的省级颜色。
- 地图连接线只读取 `jimi-subordination`，并在渲染前再次拒绝跨 `jimiKind` 的关系。
