# 朵甘行都司 1600 年点位审计

审计日期：2026-08-05  
时间切片：公元 1600 年（万历二十八年前后）  
标准区域名：朵甘。用户需求中的“甘朵”按历史文献常用名校正为“朵甘”。

## 录入边界

本次录入朵甘行都司、陇答卫、宣慰司、招讨司、万户府和千户所，共 32 个点位：15 个一级点位、17 个二级点位。

教王、法王及其他宗教领地只保留在审计范围内，不录入正式点位数据。

## 一级点位

### 军事机构

1. 朵甘行都司（正式名：朵甘卫都指挥使司）
2. 陇答卫指挥使司
3. 沙儿可万户府
4. 乃竹万户府
5. 罗思端万户府
6. 别思麻万户府

《明史》卷 331 作“列思麻万户府”；万历《大明会典》卷 124 作“别思麻万户府”。本项目采用万历名录形式，保留“列思麻”为名称变体。

### 土官衙门

宣慰司三：

- 朵甘宣慰使司（正式名：朵甘思宣慰使司）
- 董卜韩胡宣慰使司
- 长河西鱼通宁远宣慰使司

招讨司六：

- 朵甘思招讨司
- 朵甘陇答招讨司
- 朵甘丹招讨司
- 朵甘仓溏招讨司
- 朵甘川招讨司
- 磨儿勘招讨司

宣慰司、招讨司和万户府均作为一级点位显示。它们与朵甘行都司属于同一朵甘名录范围，但现有关系模型不支持在不同 `jimiKind` 之间虚构直属关系，因此不录入跨类别父子线。

## 显示等级与关系

- 都司、行都司、留守司、卫、元帅府和万户府使用军事一级显示规则。
- 所使用军事二级显示规则。
- 朵甘行都司与陇答卫保留一条军事名录关系线。
- 17 个千户所保留与朵甘行都司的名录关系线，但二级线不显示流光。
- 宣慰司、招讨司、万户府是一级点位，作为独立一级根点位参与总览显示；不为缺少直接文献依据的跨类别隶属关系补线。

## 来源校勘

1. 《明史》卷 331 明确记载朵甘设置宣慰司、招讨司、元帅府、万户府，列出六个招讨司、四个万户府和十七个千户所。
2. 万历《大明会典》卷 124 记载朵甘卫都指挥使司、陇答卫、三宣慰司、六招讨司、四万户府及十七千户所。网页文本的千户所名录在渲染时缺少开头四名，因此数量以原文总数为准，缺失的前四名使用名录交叉校勘补回。
3. 开放协作名录仅用于补充名称异文和交叉核验，不作为坐标或跨类别直属关系的唯一依据。

地点坐标目前均为区域级代理点，使用 `area_only` 精度；招讨司和部分万户府、千户所的具体晚明治所仍待专题史料复核。
