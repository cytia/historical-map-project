# 历史边界重建规范

本文件记录历史政区边界进入公开仓库前必须满足的来源、方法和发布条件。

## 当前结论

- CHGIS Temporal Gazetteer 可用于地名、时段、治所坐标和记录 ID 的研究校勘。
- CHGIS API 的多边形记录只返回对象元数据，不返回可直接使用的面坐标。
- CHGIS V6 下载页明确限制商业使用、转售和再分发。因此，下载的府州多边形及其合并、简化或描摹成果不得默认提交到公开仓库。
- 《大明舆地图》等公共领域古地图可用于历史语境和相对关系校勘，但其比例、方向与形变不足以单独产生现代坐标下的精确边界。
- 在获得许可兼容、可引用的空间依据前，不生成名为“南京直隶边界”的正式 GeoJSON。

## 边界准入条件

一个边界进入 `data/periods/` 前必须同时满足：

1. 每项空间来源具有明确的公开再分发或衍生许可。
2. 记录目标年份、重建者、重建方法和最后校勘日期。
3. 至少有一项历史文献依据和一项空间定位依据。
4. 与已校勘的行政隶属和治所点没有明显冲突。
5. 标明 `boundaryAccuracy`，不得省略不确定性。
6. 通过几何有效性、异常重叠和坐标参考系校验。

## 允许的可信度

- `documented`：历史界址与空间位置均有较强依据。
- `reconstructed`：根据所辖单位、四至、河流山脉等重建。
- `schematic`：只表达大致范围，不可用于面积或边界分析。
- `disputed`：存在多个无法消解的方案，应并存展示。

由治所点生成的凸包、Voronoi 或插值区域只能作为内部计算草图，不能标为历史行政边界。

## 推荐重建流程

1. 固定公元 1600 年时间切片和单位清单。
2. 收集各府州县的四至、接壤、河山界址及迁治记录。
3. 建立许可兼容的现代自然地理参考层。
4. 在 QGIS 中逐段描绘，并为每段或每个面关联来源声明。
5. 保留争议版本，不以视觉连续性掩盖资料空缺。
6. 导出 WGS 84 GeoJSON，运行自动校验并进行人工复核。

## 公开发布合规

依据现行《地图管理条例》，在中国境内向社会公开展示或登载地图应遵守地图审核制度；历史地图由国务院测绘地理信息主管部门负责审核。公开网站上线前应确认适用流程、审图要求及互联网地图服务义务。

开发阶段可以研究数据结构和内部草图，但不得把“尚未公开发布”理解为免除数据许可、保密或地图内容表示要求。

## 继续推进条件

满足以下任一条件后再制作正式南京直隶边界：

- 获得 CHGIS 对本开源项目发布衍生几何的书面许可；或
- 找到允许再分发与制作衍生物的历史 GIS 面数据；或
- 使用许可兼容的基础数据和公开史料完成独立、可审计的人工重建。
