# 历史数据规范

## 基准与范围

- 第一时间切片：公元 1600 年左右，默认解释为万历二十八年前后。
- 第一范围：两京十三布政使司。
- 首批精度：省级边界、府与直隶州治所、县治点；县界逐步补充。
- “1600”是查询条件，不是通用模型或文件结构的硬编码常量。

## 核心实体

至少分离以下对象：

- `Polity`：政权。
- `AdministrativeUnit`：行政单位及隶属关系。
- `Place`：具有稳定空间身份的地点。
- `PlaceName`：特定时间有效的历史名称。
- `GeometryRecord`：地点、边界、路线或水系几何。
- `Source`：书目、馆藏、数据集和许可信息。
- `SourceClaim`：来源对名称、位置、隶属或边界的支持关系。

不要把地点名称当作稳定 ID，也不要把同名地点自动合并。

## 必填元数据

每条历史记录至少包含：

- 稳定且不含时代语义的 `id`。
- `validFrom` 与 `validTo`，允许不确定或开放端点。
- 数据类型和行政等级。
- 适用的来源引用。
- `confidence`：`high`、`medium` 或 `low`。
- 创建或修订说明，以及最后校勘日期。

空间记录还必须包含：

- 坐标参考系；发布 GeoJSON 统一使用 WGS 84，经度在前。
- `locationAccuracy` 或 `boundaryAccuracy`。
- 定位或边界重建方法。
- 几何所依据的时间，不得默认等于实体全部存续期。

## 时间规则

- 内部使用天文年份整数：公元 1600 年为 `1600`，公元前 221 年为 `-220`；不存在年份 `0` 的展示值。
- 对外显示转换为历史纪年或公元纪年，不直接暴露内部换算细节。
- 不能确定具体年份时保存范围和不确定性，不虚构精确日期。
- 行政单位的有效期不得超出所属政权或上级单位有效期，确有例外时记录说明。

## 历史统计规则

- 人口、户数、田赋等统计独立于行政单位保存，必须记录适用单位、史料年份、原始数值和单位、记录值或估算值、可信度与来源。
- 史料登记口数不得直接称为完整实际人口；估算值必须与史料原数并列，并说明方法和区间。
- 万历六年（1578）黄册体系下的登记值不等同于完整实际人口；军户、匠户、灶户等特殊户籍若未由原史料分列，不另行估算扣除。
- 南京直隶区首版人口、田产与赋税展示统一采用万历六年（1578）口径；缺少直接区域总额时，按完整的14府、4直隶州分项汇总，并在记录中标明汇总性质。
- 府级统计不得按县数平均拆分为县级数据；缺少县级依据时明确标记暂无可靠记录。
- 区域直接总额缺失时，可以在府级与直隶州记录完整的前提下计算区域汇总，但必须标记为估算值，记录纳入范围、计算方法，并说明未纳入的缺失项。
- 两京十三省直接记载的全国总额独立保存于 `scopeStatistics`，不挂接到京师、南京或任何单一行政单位；全国总览面板只读取该段记录。
- 原史料明确没有可换算顷亩的省份不得补造田产数。贵州《大明会典》称“田土自来原无丈量顷亩”，保留缺项并在面板脚注显示原文。
- 省级统计覆盖遵循“先查验罗列、后写入数据”：先逐府、逐直隶州列出原文、数值、单位、记录年份、统计性质、来源、可信度与缺失项，经确认后再写入正式记录和区域汇总。
- 同一府所属各县可以采用不同登记年份，但界面必须逐项显示实际史料年份，不得统一冒充时间切片当年数据。
- 田赋优先保存夏税、秋粮、本色、折色、起运、存留等原始分项。不同实物和货币单位不得无依据相加。
- 折银等统一换算仅作为分析值，必须保存换算依据、史料年份和误差说明，不得替代原始税目。
- 当前阶段不继续新增县级人口、赋税记录；县级单位和县级行政链仍在现行地图、搜索与详情中保留，已有江宁县记录作为示例。

## 空间可信度

地点精度使用：

- `exact`：遗址或旧城位置有可靠依据。
- `approximate`：可定位到现代聚落附近。
- `area_only`：只能定位到较大区域。
- `disputed`：存在多个观点。
- `unknown`：尚不可定位。

边界精度使用：

- `documented`：有较强空间与文献依据。
- `reconstructed`：由辖属、四至和自然地理重建。
- `schematic`：仅表达大致范围。
- `disputed`：存在重要争议。

不确定边界在界面中必须使用弱化样式、虚线或说明，不能与确定边界同样呈现。

边界制作还必须遵守 [历史边界重建规范](boundary-reconstruction.md)。

## 来源与授权

每个来源记录标题、作者或机构、版本、卷页、馆藏或网址、访问日期、许可及引用方式。

来源优先级：

1. 同时期官方文献、地图和可靠影像。
2. 经过校勘的历史地理研究与学术 GIS。
3. 地方志、考古报告和专题研究。
4. 现代工具书与开放协作数据，仅作线索或交叉验证。

新增地点和空间记录默认优先采用允许商业使用、允许必要衍生且可审计的来源，或由项目依据公版史料独立重建。CHGIS 保留为待书面授权的研究校勘来源，不再作为新增数据的默认首选；未取得覆盖具体发布场景的授权前，其受限内容不得进入商业发布包。

规则：

- 免费访问不代表允许再分发，公益用途也不豁免许可要求。
- CHGIS、CCTS 和扫描古籍逐项记录版本与权利声明。
- 授权不明的数据不得进入发布包；可保留书目引用和人工校勘结论。
- 衍生边界记录使用过的来源和重建方法，不能把推测标为原始资料。
- 原创数据与第三方数据分开授权，第三方条款优先。

## 采集与校勘流程

1. 建立行政名录和稳定 ID，不先画边界。
2. 录入有效时间、隶属关系、治所和来源。
3. 独立定位地点并标记精度。
4. 依据辖属、四至、古地图与自然地理重建边界。
5. 由第二来源交叉校验；争议保留多个主张，不强行合并。
6. 运行结构、拓扑、时间和授权校验。
7. 通过审查后生成发布数据；不直接编辑生成产物。

## 自动校验最低要求

- ID 唯一且引用存在。
- 时间范围有效，父子隶属时间相容。
- 名称、坐标、几何和来源满足必填规则。
- 经纬度范围、坐标顺序和参考系正确。
- 多边形闭合、方向一致且无非法自交。
- 同一时间同级政区的异常重叠被报告。
- 发布数据不包含许可禁止再分发的来源文件。

校验失败不得静默修正历史事实；自动修复只用于可证明安全的格式问题，并保留变更记录。

## 南京县级名录校勘说明

公元 1600 年切片的南京行政名录依《明史·地理一》逐府、逐州录入。卷首总目记载十四府、四直隶州、十七属州、九十七县；逐项“领县”及县名合计则为九十六县。项目采用能够逐名核验的九十六县，不为满足总数虚构缺名县，并保留这一总目与分项之间的史料差异。

县治优先采用覆盖 1600 年的 CHGIS Temporal Gazetteer 点记录。海州、通州、霍丘县和灵璧县未取得合适的同期点，暂以现代治所附近的近似坐标代理并降低可信度，等待地方志或历史地名研究复核。
