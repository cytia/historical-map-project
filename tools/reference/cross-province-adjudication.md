# 跨省争议裁决记录

四组 cross-province 争议的处理结果。这四组决定省级边界，两侧省份在裁决前都无法定稿。

问题来自拼装法的一个前提：治所落在哪个现代县内，该县就归哪个历史单位。当两个分属不同省的
历史单位的治所落进同一个现代县时，这个前提失效。

裁决日期：2026-08-14  
空间依据：geoBoundaries CHN ADM2（ODC PDDL 1.0）、Natural Earth 河流（public domain）  
文献依据：《明史》地理志（各条分列）

## 结论：四组均为边缘邻近假象，非真实辖境重叠

每一组都是同一种情况——一方治所深入现代县内部，另一方紧贴该县边界：

| 组 | 单位 | 距现代县边界 | 判读 |
| --- | --- | ---: | --- |
| Linxian | 临县（山西汾州） | 20.28 km | 该县主体 |
| | 葭州（陕西延安） | 2.43 km | 越界溢出 |
| Fuguxian | 保德州（山西太原） | 0.27 km | 越界溢出 |
| | 府谷县（陕西葭州） | 2.31 km | 边缘 |
| Yunxixian | 郧西县（湖广郧阳） | 17.98 km | 该县主体 |
| | 上津县（湖广郧阳） | 4.24 km | 同省，非跨省冲突 |
| | 白河县（陕西兴安） | 0.37 km | 越界溢出 |
| Huangmeixian | 黄梅县（湖广蕲州） | 11.58 km | 该县主体 |
| | 德化县（江西九江） | 0.67 km | 越界溢出 |

现代县界是 2017 年的行政区划，与明代辖境没有继承关系。一个治所落在邻县境内 0.3–2.4 公里
处，说明的是现代县界从该治所旁边划过，不说明两个历史单位共有辖境。

据此，每组把现代县判给深入其内部的一方，紧贴边界的一方另由其自身所辖的其他现代县承担。
这不改变任何历史隶属判断，只是修正拼装法在县界附近的取值。

### 各组归属

- **Linxian** → 临县（山西汾州府）。葭州治所在黄河西岸陕西一侧，其辖境由陕西侧现代县承担。
- **Fuguxian** → 府谷县（陕西葭州）。保德州治所距边界仅 0.27 km，属越界溢出，其辖境归山西
  侧现代县。
- **Yunxixian** → 郧西县（湖广郧阳府）。白河县属陕西兴安州，辖境在汉江上游陕西一侧。
  上津县与郧西县同属郧阳府，二者之争不跨省，留待府级阶段（见 cross-prefecture 层）。
- **Huangmeixian** → 黄梅县（湖广蕲州）。德化县为九江府附郭，其辖境在长江以南江西一侧。

## 未采用的依据，及原因

原计划以黄河主泓裁决晋陕两组，因为府谷县与保德州治所相距仅 1.7 公里、实际隔河相望，
以河为界是明代该段的实际形态。**该方案因空间依据精度不足而放弃。**

`public/reference/natural-reference.geojson` 的黄河几何来自 Natural Earth，在府谷—保德河段
0.5°×0.7° 范围内只有 14 个顶点，相邻顶点间距 1–8 公里：

| 单位 | 距 NE 黄河 |
| --- | ---: |
| 府谷县 | 0.6 km |
| 保德州 | 2.0 km |
| 葭州 | 1.8 km |

治所到河的距离小于河流几何本身的顶点间距，因此该几何无法判定治所位于哪一岸。实测中
按最近线段方向叉积判别，得到府谷与保德同在一岸的结果，与二者隔河相望的史实矛盾——这不是
史实错误，是几何分辨率不足产生的伪结果。

这正是徒手描绘方案失败的同一个原因：吸附目标的精度低于所需精度时，产出的线由操作者的手
决定，不由证据决定。

**若需以黄河主泓作为正式界线**（府级阶段很可能需要），应先按 `SOURCES-ALLOWLIST.md`
从 SRTM GL1 提取该河段河道，再据以裁决。本次裁决不依赖河道几何，故不阻塞省级推进。

## 遗留

- 上津县 / 郧西县（同属郧阳府）的县界划分留待府级阶段。
- 晋陕黄河段的精确河道线待 SRTM 提取后建立，用于府级边界与 `boundaryAccuracy` 升级。
- 本记录的结论应在写入 `data/geometries/` 时作为重建方法说明的一部分引用。
